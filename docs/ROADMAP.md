# Roadmap

These are planned directions, not implemented features.

- Dataset adapters with audited units and label mappings for permitted public intrusion datasets.
- Session-aware or time-aware validation and independent external testing.
- Probability calibration and validation-based threshold selection.
- Local per-flow attribution with clearly documented explanation limits.
- Reproducible experiment CLI, configuration files and environment lockfiles.
- Authorized live flow ingestion after the offline model is evaluated on representative traffic.
- Tests for Streamlit interactions and additional malformed CSV cases.

The first milestone is a verifiable offline workbench, with transparent synthetic demonstrations and honest performance reporting.
